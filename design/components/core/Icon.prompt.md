Monochrome glyph wrapper around the Lucide icon set — use for every icon in this system; never hand-draw SVG.

\`\`\`jsx
<Icon name="message-circle" size={20} />
<Icon name="sparkles" size={16} color="var(--color-fin)" />
\`\`\`

Renders as a CSS mask so the glyph always inherits \`currentColor\`. Names are Lucide kebab-case.

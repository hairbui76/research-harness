# v1.1 Conversation-first Research Workspace — Implementation Plan

**Status:** executing since 2026-09-03, on the researcher's instruction to finish `ROADMAP.md`
(that instruction is the explicit "proceed" the roadmap's *Next Product Track* requires).
**Specs (authoritative design):** `docs/superpowers/specs/2026-09-03-*.md`.
**Outcomes and gates:** `ROADMAP.md` — *Cross-cutting Foundation — Research Harness Design
System*, Phases 18–21. **Product:** `PRODUCT.md` §26, §30, §39, §40, §42 M–Q.
**Process:** a project manager plus parallel subagents with disjoint file sets; every task
passes the gates in `docs/architecture/conventions.md` before it reports; the PM commits at
gates. Nothing in this plan weakens a v1.0 invariant: canonical state stays authoritative,
`.research/` stays disposable, mutation flows through capabilities, and no message,
attachment, or graph edge becomes accepted scientific state without review.

## 0. Shared contracts (locked here so parallel tasks agree)

### 0.1 Stable identities (`domain/ids.py`)

| Prefix | Type | Object | Counter |
|---|---|---|---|
| `CS` | `ConversationSessionId` | conversation session | project |
| `M` | `MessageId` | message | project (stable across sessions) |
| `SA` | `SessionAttachmentId` | session attachment | project |
| `CP` | `ContextPackId` | context pack / `Context used` receipt | project |

Composer references are `@` + id (`@W0017`, `@E0482`, `@C0041`, `@CS0001`, `@M0042`,
`@SA0003`, `@RQ0002`, `@D0001`). Manuscript objects have no counter id; the graph names them
`file:<relative path>` and anchors by their existing `ManuscriptAnchor` identity.

Deep links: `rh://<kind>/<id>[?query]` — `rh://artifact/A0017-3?page=6&block=B0081`,
`rh://evidence/E0482`, `rh://claim/C0041`, `rh://session/CS0001?message=M0042`,
`rh://attachment/SA0003`, `rh://manuscript/main.tex?line=120`. The resolver validates the
project, the object's existence, authority, privacy, and anchor freshness before anything
navigates to or includes the target.

### 0.2 Workspace layout additions (`workspace/layout.py`)

```text
conversations/CS0001/session.yaml            durable session record (title, timestamps, visibility, defaults)
conversations/CS0001/messages.jsonl          append-only transcript (one Message per line)
conversations/CS0001/attachments/SA0001.yaml session attachment metadata
conversations/CS0001/attachments/SA0001.pdf  original bytes, immutable once ready
conversations/CS0001/context/CP0001.json     ContextPack + receipt for one model call
conversations/CS0001/summary.md              derived, regenerable
.research/graph/research-graph.db            ResearchGraph projection (disposable)
.research/build/manuscript/<build_id>/       compiler outputs: pdf, log, synctex, build.json
.research/cache/attachments/                 thumbnails and page previews (disposable)
```

`conversations/` is durable but private: the generated workspace `.gitignore` lists it, and
export/share is a separate explicit action. Deleting `.research/` may not lose a transcript,
an attachment, a manuscript file, or any canonical object.

### 0.3 Vocabularies (`domain/conversation.py`, `domain/graph.py`)

- `AuthorityLabel`: `accepted | candidate | qualified | contested | stale | private`.
- `Visibility`: `private` (never leaves the machine unless policy explicitly allows) |
  `project` (may reach the selected provider under the egress policy).
- `MessageRole`: `user | assistant | system | tool`.
- `AttachmentState`: `selected | validating | ready | sending | session_only | promoting |
  in_corpus | failed`.
- `ContextClass`: `policy | accepted_state | current_session | prior_sessions | attachments |
  corpus_blocks | discovery`.
- `OmissionReason`: `token_budget | privacy_policy | egress_blocked | unsupported_media |
  stale | low_relevance | unresolved_reference | conflicts_with_accepted`.
- `PromotionTarget`: `note | question | claim_candidate | decision_candidate`.
- Graph `NodeKind`: `project session message attachment work version artifact section
  paragraph table figure equation reference evidence claim question decision synthesis
  manuscript_file manuscript_anchor citation`.
- Graph `EdgeKind`: deterministic `contains version_of artifact_of cites attached_to
  anchored_at mentioned_in`; scientific `supports contradicts qualifies derived_from
  depends_on`. Every edge carries `origin` (`structural | accepted | model_proposed |
  researcher`), `authority` (`AuthorityLabel`), `status`, and a source pointer.

### 0.4 Capability names

Registered in `capabilities/`, exposed through HTTP (`POST /capabilities/<name>`), MCP, and
the CLI exactly like the v1.0 set. Reads are marked (r); everything else mutates.

- **P18** `session.create`, `session.rename`, `session.list` (r), `session.get` (r),
  `session.search` (r), `session.send`, `session.stop`, `session.retry`, `session.promote`,
  `session.summarize`, `context.preview` (r: assemble a pack without sending),
  `context.get` (r: `{session, pack}` → the same `ContextPackView` as `context.preview`, for
  a receipt recorded on a past message), `provider.list` (r: `ProviderCatalog{models: [{id,
  label, provider, egress_class: local|external, input_media, context_tokens, vision,
  available, unavailable_reason, default}]}` derived from the router configuration and the
  egress report, so a client can offer a model selector without knowing provider rules).
  The CLI group is `research chat` (`research session` already names the v1.0 working
  session summary).
- **P19** `attachment.add`, `attachment.remove`, `attachment.check_send` (r),
  `attachment.resolve_identity` (r), `attachment.save_to_corpus`.
- **P20** `graph.resolve` (r), `graph.autocomplete` (r), `graph.neighbors` (r),
  `graph.query` (r), `graph.provenance` (r), `graph.status` (r); rebuild joins the existing
  `rebuild` command and capability.
- **P21** `manuscript.files` (r), `manuscript.read_file` (r), `manuscript.write_file`,
  `manuscript.compile`, `manuscript.build` (r), `manuscript.synctex` (r),
  `manuscript.suggest`, `manuscript.apply_suggestion`.

HTTP additions in `server/app.py` (each one updates `EXPECTED_ROUTES` in
`tests/contract/protocol/test_http.py` on purpose):

- `POST /sessions/{session_id}/attachments` — multipart byte intake. The one documented
  non-capability write; it writes only session-only state and then calls `attachment.add`
  for the metadata, so the capability layer still owns the mutation.
- `GET /sessions/{session_id}/attachments/{attachment_id}/bytes` and `/preview`.
- `GET /runs/{run_id}/events` — server-sent events for a streaming model call. Event
  contract (each `data:` is one JSON object; the stream ends after a terminal `status`):
  - `event: delta` — `{"message_id": "M0042", "attempt": 1, "text": "<appended text>"}`
  - `event: status` — `{"run_id": "...", "state": "queued|running|succeeded|failed|cancelled|incomplete", "message_id": "M0042", "attempt": 1, "context_pack_id": "CP0007", "detail": "<optional>"}`
  - `event: error` — `{"code": "<stable code>", "message": "...", "retryable": true}`
  The daemon persists every delta into the message before emitting it, so a client that
  reconnects reads the same content from `session.get`; `incomplete` means the provider
  stream stopped early and the partial content was kept.
- `GET /manuscript/builds/{build_id}/pdf`.

### 0.5 Layering additions (`docs/architecture/conventions.md` table)

| Package | Owns | Must NOT import |
|---|---|---|
| `conversation/` | sessions, messages, attachments, context packs, promotion, save-to-corpus | cli, server, protocol |
| `graph/` | the ResearchGraph projection and its queries; disposable | providers, cli, server |
| `manuscript/` (extended) | files, compile, synctex, suggestion diffs | cli, server, protocol |

`capabilities/` wraps these; `server/`, `protocol/`, `cli/` stay thin clients.

### 0.6 Frontend conventions

- `design/` is `@research-harness/design`: strict TypeScript, React 18 peer, ESM + CSS + d.ts.
  Consumers import `@research-harness/design` and `@research-harness/design/styles.css`.
- Components take typed view models and callbacks. No `fetch`, no daemon client, no
  research rules inside `design/`.
- Colour comes from semantic tokens only. Raw palette literals (`#hex`, `rgb()`, `oklab()`)
  are allowed only under `design/src/tokens` and `design/src/themes`;
  `design/scripts/check-tokens.mjs` fails the lint otherwise, and the Web client gets the
  same check.
- Themes switch on `:root[data-theme="dark"|"light"]` (dark default), density on
  `[data-density="comfortable"|"compact"]`, and every transition respects
  `prefers-reduced-motion`.
- No CDN. Fonts are system stacks until licensed files are self-hosted; icons come from the
  locally bundled `lucide-react`; KaTeX CSS and fonts ship from the package.
- Tests: vitest + Testing Library + `axe-core` on every interactive component; DOM snapshot
  per theme × density variant stands in for screenshot regression (no browser available);
  a token contrast check computes WCAG 2.2 AA ratios for every semantic text/surface pair.
- Package gates: `pnpm -r typecheck`, `pnpm -r lint`, `pnpm -r test`, `pnpm -r build`.

## 3. Risks and the answers we chose

- **No browser for visual regression** — DOM snapshots per variant plus a computed contrast
  check; recorded honestly as the gate's form.
- **LaTeX toolchain on the test machine** — hermetic fake toolchain for the suite; a real
  `tectonic` compile for the dogfood gate; missing toolchain yields setup guidance, never a
  source change.
- **Streaming through a capability-only write surface** — `session.send` is the capability;
  the run's events are a read stream; interruption preserves content and marks it incomplete.
- **Byte uploads** — one documented route writes session-only bytes, then hands metadata to
  `attachment.add`; canonical state is never written outside capabilities.
- **Graph authority creep** — the graph stores `authority` on every node and edge and is
  deleted in every rebuild test; the resolver reads canonical objects for the final answer.
